# 🍽️ BiteWise – Your Mood, Your Food

A mood-based food recommendation web application developed as part of a group project at Sunway University.

BiteWise explores the relationship between emotions and food choices by providing users with personalised food suggestions based on their current mood. The project focuses on interactive web design, responsive layouts, and improving user experience through engaging frontend features.

🌐 **Live Demo:** https://bitewisesu.netlify.app/

---

## 📌 Project Overview

BiteWise is a multi-page web platform designed to make food discovery more interactive. Users can explore food recommendations, navigate different sections of the website, and interact with forms through a responsive and user-friendly interface.

The project was developed collaboratively using a shared workflow, with each team member responsible for different modules of the application.

---

## 🛠️ Technologies Used

- **HTML5**  
  Used to create the structure and content of the website.

- **CSS3**  
  Used for styling, responsive layouts, animations, and visual design.

- **JavaScript**  
  Used to implement interactive features including navigation, dark mode functionality, and form validation.

---

## ✨ Features

### 🍜 Mood-Based Food Recommendations
- Provides food suggestions based on user mood selections.
- Creates a more personalised browsing experience.

### 📄 Multi-Page Website
Includes:
- Home
- About
- Food Spots
- Contact
- Login / Sign-Up

### 🌙 Interactive User Interface
- Dark mode toggle
- Responsive hamburger navigation menu
- Smooth scrolling
- Hover animations
- Mobile-friendly layouts

### ✅ Form Validation
- Validates user input before submission.
- Checks formatting of:
  - Names
  - Email addresses
  - Contact numbers
- Redirects users after successful validation.
